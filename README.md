### GeneOntology.py
- Use for performing gene set enrichment analysis on different differentially expressed gene datasets using the biological process, molecular function and KEGG gene sets 
- Obtain bar plots and color maps that all plot combined score across the x-axis and matching GO terms across the y-axis
